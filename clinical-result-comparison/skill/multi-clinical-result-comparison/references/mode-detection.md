# Evidence Set Routing

## Primary routing principle

First identify whether the selected sources describe one trial, multiple trials, or an uncertain mixture.

- One trial with multiple disclosures → **trial-level evidence-chain synthesis** (the default visible unit for a single trial).
- Multiple independent trials → **cross-trial comparison, comparison-first and domain-aligned** (the primary deliverable), with compact per-trial context only as support.

The routing question is not “one narrative per trial plus a small comparison”; when users select several trials, the decision-relevant output is the inter-trial alignment by outcome domain (efficacy, safety, PK/PD, PRO) that helps judge which is better or worse.

## One trial with multiple disclosures

Use trial-level synthesis when sources share a trial identity and the same underlying clinical question. Consolidate duplicate cutoffs and analyses, order distinct evidence states by source-supported timing, and interpret the entire trial across design, efficacy, safety and maturity. Do not compare disclosures as winners or losers.

## Multiple independent trials

Treat cross-trial comparison as the primary analysis object. Organize the report by outcome domain: efficacy, safety, PK/PD, PRO, and the design/baseline context that qualifies them. Provide one compact trial-context block per trial so each aligned value can be interpreted, but do not lead with a full trial-by-trial narrative. A per-cluster who-is-better judgment is expected when evidence supports it, with an explicit comparability and confidence label. See `cross-trial-comparison.md`.

## Uncertain identity

Use exact registry identifier, trial acronym/name, explicit previous-report language, intervention/control regimen, randomized sample and arm structure, eligibility, geography, and matching endpoint values together. If identity is probable but not confirmed, say “可能属于同一试验/项目，原文不足以确认” and preserve the uncertainty in the evidence chain. Do not silently merge records.

## Cohort boundaries

A shared trial name or registry identifier does not automatically merge extensions, substudy populations, biomarker cohorts, post hoc analyses, or different treatment phases. Preserve each distinct cohort or analysis population and explain its relationship to the trial core.

## Chronology

Order evidence states by data cutoff, stated follow-up, explicit analysis milestone, then disclosure/publication date. Input order and database order are never clinical chronology.
