## 六、综合解读

### 6.1 可以放在一起看的观察

四份材料均支持同一项随机、双盲、III 期研究的整体框架：532 例患者按 1:1 分配至依沃西单抗联合化疗或替雷利珠单抗联合化疗。PFS 是主要终点，OS 是关键次要终点。较早切点的 PFS 结果与较长随访的 OS 结果在同一研究内呈现一致的有利方向，并分别报告了 HR 0.60 和 0.66 以及统计学支持。

A/D 应合并理解为一个 PFS 分析状态，B/C 应合并理解为一个 OS 分析状态。PFS 到 OS 是从疾病进展到生存结局的补充信息，而不是将两个终点合成一个数值或两个独立研究结果。

### 6.2 需要分别看的观察

- PFS 与 OS 的定义、事件和成熟度不同，不能用 OS 中位数变化解释 PFS 的后续变化；所选材料没有提供较长随访下的更新 PFS 估计。
- 总体人群与 PD-L1 TPS 亚组不能混为同一分析层级。亚组中依沃西单抗组 OS 中位数均为 NE，且未报告亚组交互检验，因此不能判断 TPS <1% 与 TPS ≥1% 哪一层级获益更大。
- ≥3 级治疗相关不良事件、治疗相关严重不良事件、免疫相关不良事件和出血事件的定义并不完全相同，且 C 的替雷利珠单抗安全性分母为 265 例。不能仅按比例大小判定总体安全性优劣。
- 证据 D 报告了总体中央型肿瘤、肿瘤空洞和大血管包绕比例，但没有提供逐组分布；这些信息不能替代完整的基线可比性表。

### 6.3 证据如何变化

较早证据在 2025-02-28 数据截止、10.3 个月中位随访时报告了主要终点 PFS。随后材料在 2026-02-27 数据截止、21.4 个月中位随访时新增 OS：依沃西单抗联合化疗相对于替雷利珠单抗联合化疗的死亡 HR 为 0.66，单侧 p=0.0017，达到预设 p<0.0049 边界。证据 C 说明该分析在 204 例死亡时触发，而原计划约 225 个事件；因此疗效判断得到加强，但 OS 仍应视为中期成熟度，而非最终结果。

两条 PFS 材料的总体 PFS 中位数、HR 和显著性结果相同；两条 OS 材料的数据截止、随访和 OS 核心估计相同。PFS 和 OS 各自的第二份材料提供亚组、检验程序、事件数或安全性等补充内容，但不增加独立患者或独立分析状态。

### 6.4 安全性与证据成熟度

安全性信息从较早 PFS 材料的 ≥3 级治疗相关不良事件、≥3 级免疫相关不良事件和治疗相关出血，扩展到较晚 OS 材料的 ≥3 级治疗相关不良事件和 ≥3 级出血。证据 B 原文称安全性“可管理”、与既往报告一致且未观察到新安全性信号；这是材料中的定性判断，不能替代完整的事件谱和暴露调整分析。

较晚切点报告的 ≥3 级治疗相关不良事件比例为依沃西单抗组 69% 对替雷利珠单抗组 59%，较早材料为 64% 对 54%。由于实际治疗暴露时长未报告，不能将比例增加单独解释为风险随时间恶化。材料也未报告因不良事件停药、减量或中断、治疗相关死亡及完整的所有级别不良事件，因此长期安全性成熟度仍有限。

## 七、临床开发启示

- **已观察到的信号：** 在该随机研究及其总体人群中，依沃西单抗联合化疗的 PFS 和 OS 均相对于替雷利珠单抗联合化疗报告了有利的研究内比较结果；PFS 主要终点和 OS 关键次要终点均有统计学支持。PD-L1 TPS <1% 和 ≥1% 亚组也分别报告了 PFS 或 OS 的有利 HR。
- **证据强度：** 证据来自 532 例、1:1 随机、双盲、III 期研究；PFS 由独立影像学审查委员会按 RECIST 1.1 评估，OS 按层级程序检验。强度仍受 OS 在 204 个事件时触发、两组中位 OS 上限为 NE、重复披露以及安全性数据不完整的限制。
- **选定证据中的可能差异：** 在 HARMONi-6 的既定人群、方案和时间点内，两个关键疗效终点均支持依沃西单抗联合化疗相对于活性对照的有利方向。这是该研究内的随机比较结果，不外推为其他人群或其他方案中的效果。
- **仍未证实：** OS 最终分析、较长时间的生存成熟度、更新后的 PFS、亚组间获益差异、症状或生活质量获益、应答深度和持续时间，以及按实际暴露和完整安全性结局校正后的长期风险仍未由所选材料证实。

## 八、最终结论与信息缺口

- **当前最可靠的判断：** HARMONi-6 在既往未治疗的晚期鳞状 NSCLC 人群中，报告依沃西单抗联合化疗相对于替雷利珠单抗联合化疗改善 PFS；在更长随访下，首次计划 OS 分析也达到预设统计边界。两类结果均来自同一随机队列。
- **可以支持的有限比较：** 可以在 HARMONi-6 内分别解读 PFS 和 OS 的治疗组与活性对照组差异，并将 PFS 与 OS 作为互补疗效证据；可以描述 PD-L1 两个预设亚组的各自结果，但不能比较两个亚组的相对获益大小。
- **无法支持的结论：** 不能把 A/D 或 B/C 的重复披露计为独立确认；不能把 OS 中期结果写成最终结果；不能据不同安全性定义、分母或暴露时长缺失判定总体安全性优劣；不能由这些材料单独推断研究外人群的疗效或长期风险。
- **最影响下一步判断的信息缺口：** OS 最终分析及更成熟的置信区间和事件数；更新后的 PFS；PD-L1 亚组交互检验；客观缓解、完全缓解、缓解持续时间、症状和生活质量；实际治疗暴露；各级别不良事件全貌；因不良事件停药、减量、中断和治疗相关死亡。
