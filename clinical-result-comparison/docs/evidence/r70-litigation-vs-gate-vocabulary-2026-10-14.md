**读法**：排在最前面的 `成熟度` / `可比性` / `判断强度` / `解读边界` 是**模板自带、门禁根本不拒**的合法词；

两类都指向同一个根因：**禁令以「常见形态清单」出现，模型只能逐词推演合法性**——它不知道清单是不是穷尽，
所以每次遇到模板近义词都要重新裁一次。

## §2 改动（一个变量：禁令的表述方式；外加三项不参与判据的卫生项）

| 文件 | 改动 | 归属 |
|---|---|---|
| `SKILL.md`（硬规则段后） | 新增一段：**「判据是语义，不是词表（据此自检，不要背诵）」**——列出**永远合法**的材料属性词（时点/人群/口径/定义/方向/成熟度/证据强度/判断强度/解读边界/组内证据关系/归属组/归组依据），说明词表只是常见形态、**不完整、不必逐词核对**，拿不准就**跑一次 `check_report.py` 由脚本判定**（FAIL 才改，WARN 不是失败） | 主判据 |
| `references/toolbox.md` §「Questions this file answers…」 | 新增 2 条 FAQ：①「模板自带列名看起来像被禁词，安全吗」→ 判据是**语义不是拼写**，材料属性永远合法，只有「把我们的分析/分级/过程写成交付物」才 FAIL，**清单不用背，跑脚本**；②「`（高/中/低可比性）` 这种列头呢」→ 合法 | 主判据 |
| `templates/cross-trial-report.md`（第七节表前） | 给 `判断强度（高/中/低可比性）` 列加一句：**该列名合法**（写的是材料之间对比的把握程度，不是 `可比性结论`/`对齐等级` 那类自述分级），同类分类词仍不得出现，把差异写进 `主要限制`/`解读边界` | 主判据 |
| `templates/mixed-comparison-report.md`（第五节表前） | 同上手法，给 `证据成熟度与限制` 列加一句（`成熟度` 是最高频被怀疑的词） | 主判据 |
| `references/toolbox.md`（示例 json） | `95% CI 9.6\u20139.6` → `9.6\u201312.7`（原文示例就是 `9.6–12.7`，见同文件 :104；此前是笔误，**会被模型照抄成无意义 CI**） | 卫生 |
| `scripts/make_chart.py --no-validate` | help 文本标注 **DEBUG ONLY**：跳过校验产出的图仍可能被报告门禁拒 | 卫生 |

**为什么这不是「告诉模型答案」而是「删掉一个假问题」**：词表禁令的本意是「不要写我们自己的分析方法/分级」，
而模板列名（成熟度/判断强度/…）写的是**材料属性**——门禁从来没拒过它们（§3 正反向对照为证）。
模型反复仲裁的是一个**我们自己造出来的假问题**。这版改动删的是这个问题，不是放松门禁：所有被拒词
一条不少，`check_report.py` 与断言集**一行未动**。
