# 临床结果综合分析报告

**一句话结论：** HARMONi-6 在既往未治疗的晚期鳞状非小细胞肺癌人群中，报告依沃西单抗联合化疗相较替雷利珠单抗联合化疗显著改善 PFS；在更长随访下，预设 OS 分析亦达到统计学显著边界。四份披露应去重为一个 PFS 核心分析状态和一个 OS 核心分析状态；OS 结果增强了总体疗效判断，但该分析仍属中期，长期安全性与最终生存成熟度尚不完整。

## 一、核心发现

### 一线晚期鳞状非小细胞肺癌的疾病控制与生存

- **核心终点或观察：** 主要终点为独立影像学审查委员会按 RECIST 1.1 评估的 PFS；OS 为关键次要终点，在 PFS 达到统计学显著后按层级程序检验。
- **主要观察：** 截至 2025 年 2 月 28 日，中位随访 10.3 个月，依沃西单抗联合化疗组与替雷利珠单抗联合化疗组的中位 PFS 分别为 11.1 个月和 6.9 个月，HR 0.60（95% CI 0.46-0.78，单侧 p<0.0001）。截至 2026 年 2 月 27 日，中位随访 21.4 个月，两组中位 OS 分别为 27.9 个月和 23.7 个月，死亡 HR 0.66（95% CI 0.50-0.87，单侧 p=0.0017），达到预设 p<0.0049 的疗效边界。
- **证据关系：** 两份 PFS 披露共享相同的总体 PFS 中位数、HR 和显著性结果，构成一个核心 PFS 分析状态；无明确截止日期的 PFS 披露新增 PD-L1 亚组、肿瘤解剖特征和部分安全性信息。两份 OS 披露共享相同的数据截止、随访及总体 OS 估计，构成一个核心 OS 分析状态；其差异主要是层级检验、PD-L1 亚组、事件数和定量安全性等补充内容。

## 六、综合解读

### 6.1 可以放在一起看的观察

四份披露均描述 HARMONi-6 的同一随机队列：532 例既往未治疗的晚期鳞状 NSCLC 患者按 1:1 分配至依沃西单抗联合化疗或替雷利珠单抗联合化疗。PFS 是主要终点，OS 是关键次要终点。研究内随机比较显示，PFS 和 OS 均呈依沃西单抗联合化疗有利的方向，并分别获得预设统计检验支持。

去重后，PFS 与 OS 各形成一个核心分析状态。OS 结果不是第二项独立研究，而是在更长随访下为同一研究新增的关键生存终点；因此它增强的是同一研究疗效链条的完整性，而不是独立重复性。

### 6.2 需要分别看的观察

PFS 与 OS 的定义、事件类型、数据截止和成熟度不同。所选 OS 披露虽然回顾了此前 PFS 显著改善，但没有提供 2026 年截止下的新 PFS 数值，因此不能把 OS 分析当作 PFS 更新。

总体人群结果与 PD-L1 TPS 亚组结果必须分层解读。各 PD-L1 亚组均报告有利 HR，但没有报告亚组交互检验；两个亚组 HR 的数值差异不能证明某一 PD-L1 层级获益更大。OS 亚组中依沃西单抗组中位数均为 NE，也不能把尚不可估计误读为无穷或必然更优。

安全性披露涉及≥3 级治疗相关不良事件、治疗相关严重不良事件、免疫相关不良事件及不同措辞的出血事件，定义和时间点并不完全一致。替雷利珠单抗组在较晚披露中的安全性分母为 265 例，而非随机分配的 266 例；这些结果不能脱离各自定义和分母进行简单比例排名。

### 6.3 证据如何变化

可明确定位的较早状态为 2025 年 2 月 28 日截止、10.3 个月中位随访的 PFS 分析：中位 PFS 为 11.1 个月对 6.9 个月，HR 0.60。另一份首次计划 PFS 分析重复了总体核心结果，并补充 PD-L1 亚组 PFS、中央型肿瘤、肿瘤空洞、大血管包绕及部分安全性数据；由于其截止和随访未报告，不能把它排列为独立的前后更新。

截至 2026 年 2 月 27 日，中位随访增至 21.4 个月，首次计划 OS 分析报告中位 OS 27.9 个月对 23.7 个月，HR 0.66，达到预设 p<0.0049 边界。同日两份 OS 披露是同一核心分析：一份补充层级检验和 PD-L1 亚组，另一份说明 204 例死亡及分析触发背景。该 OS 结果使总体解释由“PFS 获益”扩展为“PFS 与中期 OS 均有研究内统计支持”，因此证据判断得到加强；但不能把两份 OS 披露计作两次确认。

### 6.4 安全性与证据成熟度

较早 PFS 披露中，≥3 级治疗相关不良事件为 64% 对 54%，≥3 级免疫相关不良事件为 9% 对 10%，≥3 级治疗相关出血为 2% 对 1%。较晚 OS 事件/安全性披露中，≥3 级治疗相关不良事件为 69% 对 59%，≥3 级出血为 3% 对 1%。由于实际治疗暴露、事件定义变化及个体患者随访未报告，不能把比例变化单独解释为风险随时间增加或稳定。

同日 OS/层级检验披露称安全性与既往报告一致、未观察到新安全性信号。这是原文的定性判断；所选材料没有完整报告各级别不良事件、停药、减量、中断、治疗相关死亡或暴露调整发生率，因此长期安全性结论仍有限。OS 分析达到预设统计边界，但在原计划约 225 个事件前于 204 个事件时触发，且中位 OS 置信区间上限仍为 NE，应继续保留中期分析的成熟度边界。

## 七、临床开发启示

- **已观察到的信号：** 在 HARMONi-6 的既定人群和方案中，依沃西单抗联合化疗相较替雷利珠单抗联合化疗，在主要终点 PFS 和关键次要终点 OS 上均报告有利的研究内比较结果并达到相应统计边界；PD-L1 TPS <1% 与 ≥1% 亚组也分别报告有利的 PFS 或 OS HR。
- **证据强度：** 结果来自 532 例患者、1:1 随机、双盲、III 期研究；PFS 经独立影像学审查委员会按 RECIST 1.1 评估，OS 在层级检验框架下达到预设边界。证据强度受重复披露不能独立计数、OS 仍为中期分析以及安全性结局不完整的限制。
- **选定材料中的可能差异：** 同一研究从 PFS 获益扩展到 OS 获益，表明疗效证据覆盖了疾病进展和生存两个不同层面；这是 HARMONi-6 内相对于活性对照的随机比较结果，不代表其他人群、方案或研究中的效果。
- **仍未证实：** 最终 OS 结果、更新后的 PFS、PD-L1 亚组间的差异性获益、应答深度与持续时间、症状或生活质量获益，以及经充分暴露信息支持的长期安全性仍未由所选材料证实。

## 八、最终结论与信息缺口

- **当前最可靠的判断：** HARMONi-6 支持依沃西单抗联合化疗在既往未治疗晚期鳞状 NSCLC 中相较替雷利珠单抗联合化疗改善 PFS；更长随访下的预设 OS 分析也达到统计学显著边界，使同一研究的总体疗效判断得到加强。
- **可以支持的有限比较：** 可以在 HARMONi-6 内分别解读两组的 PFS 和 OS 差异，并把两者视为互补的疗效终点；可以描述两个 PD-L1 预设亚组各自的结果，但不能比较亚组间相对获益大小。
- **无法支持的结论：** 不能把两份 PFS 或两份 OS 披露分别计作独立验证；不能把中期 OS 写成最终结果；不能依据不同定义、分母和未知暴露时长的安全性百分比作总体安全性优劣判断；不能把研究结论外推至材料未覆盖的人群或治疗方案。
- **最影响下一步判断的信息缺口：** 最终 OS 分析及更成熟的事件数和置信区间；更长随访下的更新 PFS；PD-L1 亚组交互检验；客观缓解、完全缓解、缓解持续时间、固定时间点生存率、症状和生活质量；实际治疗暴露；各级别不良事件全貌；因不良事件停药、减量、中断及治疗相关死亡。
