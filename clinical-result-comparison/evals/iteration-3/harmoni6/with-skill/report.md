# HARMONi-6 同试验证据演进报告

**结论先行：** 这 4 个文本都来自同一项 HARMONi-6 研究，不是跨试验比较；它们支持的是一条同试验证据演进链，而不是“披露赢家”。可确认的主线是：早期 PFS 首次披露已显示 ivonescimab+化疗优于 tislelizumab+化疗，随后同一研究在更长随访、更多死亡事件下给出了 OS 的后续成熟披露；重复出现的 PFS/OS 数值不应按独立证据重复计数。

## 证据演进

### 1. PFS 先于 OS，且 PFS 重复披露不构成新证据点

结果 A 给出的是最早、最完整的 PFS 首次披露：数据截止 2025-02-28，随访中位数 10.3 个月，PFS 为 11.1 个月 vs 6.9 个月，HR 0.60，单侧 p<0.0001。该结果明确指向同一试验的首个成熟终点。

结果 D 报告的 PFS 核心数值与 A 完全一致：HR 0.60、PFS 中位数 11.1 vs 6.9 个月；同时补充了 PD-L1 分层下的 PFS 结果（TPS <1%: 9.9 vs 5.7 个月，HR 0.55；TPS ≥1%: 12.6 vs 8.6 个月，HR 0.66）和若干基线特征。由于 D 没有单独给出新的数据截止或随访时间，也没有显示新的分析切点，因此应视为 A 的补充/重复披露，而不是一个新的独立 PFS 证据阶段。

### 2. OS 是后续更成熟的同试验证据，但 B 和 C 彼此重复

结果 B 与结果 C 都把数据截止放在 2026-02-27，随访中位数 21.4 个月，且都基于 204 例死亡事件。两者的 OS 主结论一致：中位 OS 27.9 个月 vs 23.7 个月，HR 0.66，单侧 p=0.0017，达到预设显著性边界。这里真正增加的是随访成熟度，而不是比较对象本身的变化。

B 强调了层级检验路径和 PD-L1 亚组 OS；C 则补充了更细的安全性数字。二者属于同一 OS 分析的并行披露，不能作为两个独立的 OS 结果重复加权。

### 3. 终点演进的方向是“同一试验内由 PFS 到 OS”，不是“不同文本之间谁更强”

就证据成熟度而言，A/D 代表的是早期 PFS 层面，B/C 代表的是更晚的 OS 层面。OS 的时间窗更长、事件数更多，因此在同一试验内部，它比早期 PFS 披露更成熟；但这只是证据阶段的推进，不是给某一文本或某一披露贴“胜出”标签。

## 关键可支持结论

- 同一试验中，ivonescimab+化疗相较 tislelizumab+化疗，在 PFS 和后续 OS 两个不同成熟度的时间点都给出了有利结果。
- 这些文本支持的是“同试验证据逐步成熟并趋于一致”，不是额外独立验证。
- 安全性总体可管理，但不同文本采用的安全性口径不同，不能把 AE 数字直接并列当成同一统计口径。

## 需要保留的限制

- 结果 D 没有单独提供数据截止时间，因此不能据此推断它一定晚于 A，只能确认它是同一 PFS 结果的补充性披露。
- 结果 B 与 C 的 OS 数字、截止和随访一致，因此应当合并理解；任何把两者当作独立 OS 证据的做法都会重复计数。
- A、C、D 的安全性指标定义不同，至少包括 treatment-related AE、grade 3+ treatment-related AE、treatment-related SAE、grade 3+ hemorrhage、grade≥3 hemorrhagic events，不能直接做数值优劣排序。
- 该组文本没有支持跨试验比较，也不支持把不同终点、不同截止、不同随访的数值混成一个统一排名。
