# 实体、术语与药名的中英写法

目标只有两条：**同一实体全篇一个写法**；**写不出来的名字不许编**。

## 0. 总流程

```
名称出现在正文
  ├─ 是常见实体（确定的中英对应） → 直接用，不必查
  ├─ 不确定或存在别名/歧义
  │    ├─ 宿主已返回成对字段 → 直接用该字段，不自己译
  │    ├─ 有药品字典工具 → 查一次（最多两次）取标准名
  │    └─ 查不到 → 按方向回退（见 §3），绝不编造
  └─ 同名多个实体 → 用语境（研发机构/靶点/适应症/阶段）消歧，取一致的那个
```

## 1. 常识优先

常见药的中英对应属于确定知识，直接用，不要浪费一次工具调用：

| 中文 | 英文 |
| --- | --- |
| 帕博利珠单抗 | pembrolizumab |
| 纳武利尤单抗 | nivolumab |
| 贝伐珠单抗 | bevacizumab |
| 曲妥珠单抗 | trastuzumab |
| 奥希替尼 | osimertinib |
| 阿达格拉西布 | adagrasib |
| 索托拉西布 | sotorasib |
| 多西他赛 | docetaxel |
| 来那度胺 | lenalidomide |
| 司美格鲁肽 | semaglutide |

判据是「我能否确信」：能确信就直接写；有一点不确定就进 §2。**不确定也不许猜**（不要把 `capivasertib` 猜成「卡匹赛替尼」这类未证实译名）。

## 2. 查字典（只查一两次）

按可用性顺序选一种即可：

1. **宿主项目已返回的成对字段——首选，零额外调用。** 例如参数化临床结果检索的返回里：
   - `arms.drugs.drug_earth_name_cn` / `arms.drugs.drug_earth_name_en`（药品中/英文名）
   - `arms.drugs.drug_earth_all_name`（名称集合，含异名，用于消歧）
   - 同类成对字段：`indication_name` / `indication_name_en`、`company.short_name` / `short_name_en`、`modality.name` / `name_en`、`clinical_endpoint.endpoint` / `endpoint_en`
   返回里有就用返回里的，**不要自己再译一遍**。
2. **药品字典工具。** 任选其一，不要为了同一个词把三个工具全试一遍：
   - TS 报告类项目：`report-query-drug`（参数 `drug_names` 传名称，`is_en` 切换中文/英文输出）；
   - 医药魔方 MCP：`pharmcube-mcp-drugBaseLiteCN`（`drugName` + `pageNo`/`pageSize`，返回 `name_short`、`drug_name_synonyms`）；
   - Linking API：`drug` 实体（取标准名与异名，用于消歧与批量标准化）。
3. **查到的候选多于一个时**，用报告语境（研发机构、靶点、适应症、阶段）挑一致的那个；不挑热度最高的，也不合并两个不同药物。

**一次查不到就停。** 连环试探（换拼写、换工具、换语言反复查）既慢又容易把错误名称写进报告。

## 3. 查不到时的回退（硬性）

| 方向 | 回退写法 | 不允许 |
| --- | --- | --- |
| 英文 → 中文 | **保留英文原名**，不翻译 | 音译、造译名、意译、缩写成臆测的中文简称 |
| 中文 → 英文 | **用拼音**（首次出现可括注中文原名） | 造英文名、按字面直译、随意挑一个相近英文药名 |

示例：

- 输入英文 `zongertinib`，查不到中文名 → 正文写 `zongertinib`，不写「宗格替尼」。
- 输入中文俗名且无英文对应 → 写拼音 `Yishujidanmu`（首次出现括注中文原名），不写 `anti-XX antibody` 这类自造英文名。
- 商品名与通用名：原文用哪个就保留哪个；需要时括注另一个（`泰圣奇（阿替利珠单抗）`），不要擅自只留通用名。

## 4. 其它实体

- **试验名与注册号**：`KEYNOTE-189`、`NCT02576574`、`ChiCTR2000031495` 原样复制——不改大小写、不加空格、不重排、不补零。同一试验全篇一致。
- **公司**：优先标准简称（`复宏汉霖`），首次出现可给全称；`short_name_en` 存在时英文文本用英文简称。
- **靶点**：沿用输入的标准写法（`PD-1`、`VEGF-A`、`EGFR`），不写成「PD1 受体」这类变体；同一靶点只用一种写法。
- **终点**：缩写首次出现给全称并括注中文（`PFS（progression-free survival，无进展生存期）`），其后统一用缩写。`PFS`/`OS`/`ORR`/`DCR`/`DoR`/`AE`/`SAE` 全篇统一大小写。
- **疾病与病理**：用标准中文名（`非小细胞肺癌`），需要时括注英文（`non-small cell lung cancer`）；不要在同一文中混用「非小细胞肺癌」与「NSCLC」两种主写法。
- **分期与治疗线**：`III 期临床`、`一线`、`二线及以上`，全篇统一表述；罗马数字与「3 级」这类不良事件分级按输入原样。

## 5. 格式统一

- 数字用阿拉伯数字；百分比与区间全篇同一格式（`9.4 个月`、`0.62（95% CI 0.48–0.80）`、`p<0.001`）。
- 中英混排：中文正文用中文标点；英文专名与缩写保持原文大小写与连字符；中英文之间是否加空格以文档既有风格为准，不来回改。
- 首次出现的缩写必须给定义；不给定义的缩写只在表格与图里使用（表头可放宽）。
