# HARMONi-6 同一试验 4 次结果披露比较报告

结论：这 4 次披露属于同一项 HARMONi-6 研究的连续公开，核心比较对象、随机分层和治疗方案保持一致，真正推进的是证据成熟度：先完成 PFS 的早期/中期披露，再出现随访更长的 PFS 完整稿，随后进入 OS 的首次成熟披露。就已披露内容看，PFS 和 OS 的方向一致，且 OS 的出现显著提高了临床结论的成熟度；但不同披露之间的安全性比例和细节口径并不完全一致，不能直接当作独立趋势比较。

## 证据成熟度变化

### 第 1 阶段：PFS 先行，证明有明确疾病控制获益

最早的披露先回答了“这个方案是否优于对照”的核心问题，且答案在 PFS 上已经明确：ivonescimab 联合化疗优于 tislelizumab 联合化疗。这个阶段的证据已经足以说明疗效方向，但还不能回答长期生存是否真正改善。

### 第 2 阶段：PFS 在更长随访下被重复确认

后续 PFS 完整稿在同一 HR 和中位 PFS 上重复了早期结论，同时给出 10.3 个月中位随访和更完整的安全性信息。它的意义不是“发现了新疗效”，而是把早期疗效信号从会议式披露推进到更完整的论文式披露。

### 第 3 阶段：OS 首次成熟，临床解释力度明显上升

当随访推进到 21.4 个月、死亡事件达到 204 例时，OS 结果首次成形。此时试验不再只是在无进展生存层面显示优势，而是进一步显示总生存也获益。对成熟度而言，这一步比 PFS 更重要，因为它把结论从“疾病控制改善”推进到“生存结局改善”。

### 第 4 阶段：OS 重复披露属于同一成熟时点的扩展，不是新的独立证据

OS 的两份文本共享相同事件数、相同中位随访和相同 HR，本质上是同一分析的不同披露载体。它们强化了结论表达，但没有再增加新的临床信息量。真正新增的，是 OS 已经成熟这一事实，而不是另一组不同的 OS 结果。

## 需要避免的误读

- 不能把 PFS 披露之间的安全性比例直接比较成“毒性升高”或“毒性降低”，因为分析口径和随访长度不同。
- 不能把同一 OS 分析的两次公开当作两次独立验证。
- 不能把 PFS 的早期阳性结果直接等同于长期生存获益，OS 数据出现之前，这一步只能算未完成。

## 总体判断

这 4 次结果披露构成一条清晰的成熟度曲线：先是 PFS 早期阳性，再是 PFS 在更完整随访下确认，最后是 OS 达到预设统计边界并正式成立。就同一试验内部的证据演进而言，结论从“存在无进展生存优势”升级为“无进展生存和总生存均获益”，这就是最关键的成熟度变化。
