# HARMONi-6 多次结果披露演进报告

**一句话结论：** 这 4 次披露显示 HARMONi-6 的证据从“PFS 已达到统计学显著、OS 仍待成熟”演进为“在更长随访和预设 OS 分析中，OS 也达到统计学显著”；因此总体疗效判断得到加强，但安全性随更长暴露显示 3 级及以上治疗相关不良事件和出血事件数值增加，风险获益判断仍需结合后续更完整安全随访。

## 一、试验与披露范围

- **分析模式：** 同试验纵向证据演进
- **共同试验：** HARMONi-6，ClinicalTrials.gov 登记号 NCT05840016
- **共同人群与方案：** 既往未治疗、不可切除 IIIB/IIIC 或 IV 期鳞状非小细胞肺癌；ivonescimab 20 mg/kg Q3W 或 tislelizumab 200 mg Q3W，均联合紫杉醇 175 mg/m² 与卡铂 AUC 5 共 4 个周期，随后单药维持；1:1 随机，按疾病分期和 PD-L1 TPS 分层。
- **纳入披露：** 结果 A、结果 B、结果 C、结果 D
- **需要区分的队列/亚组：** 总体随机人群、PD-L1 TPS <1% 亚组、PD-L1 TPS ≥1% 亚组；安全性分析集在结果 C 中为 ivonescimab 266 例、tislelizumab 265 例，结果 A 表述为所有接受至少一剂治疗者但报告计数基于 266/266 随机分组。

## 五、深度解读

### 5.1 真正新增的证据

真正新增的核心证据来自结果 B/C 的 2026-02-27 数据截止：中位随访从结果 A 的 10.3 个月延长至 21.4 个月，并进入预设 OS 分析。该分析报告 204 例死亡，ivonescimab 联合化疗相对 tislelizumab 联合化疗的 OS HR 为 0.66，95% CI 0.50-0.87，单侧 P=0.0017，达到预设 P<0.0049 边界。

结果 C 相比结果 B 不是新的 OS 分析，而是同一截止点、同一 OS 估计的更完整披露：补充了死亡例数、分组死亡比例、年龄和性别构成，以及定量安全性。结果 A 相比结果 D 也更像同一 PFS 分析的完整化披露：PFS 点估计一致，结果 A 进一步给出数据截止、随访、筛选入组流程和更完整安全事件分类。

### 5.2 疗效证据变化

早期疗效证据的基础是 PFS：ivonescimab 组中位 PFS 11.1 个月，对照组 6.9 个月，HR 0.60，95% CI 0.46-0.78，P<0.0001。该结果已经支持在 HARMONi-6 这个随机双盲 III 期试验、既往未治疗晚期鳞状 NSCLC 人群内，ivonescimab 联合化疗在 IRRC 评估 PFS 上优于 tislelizumab 联合化疗。

后续成熟度的关键不在于 PFS 数值继续改善，而在于 OS 从未成熟/未披露变成达到预设统计学边界。OS 中位数为 27.9 vs 23.7 个月，HR 0.66，且达到层级检验中预设边界。这使主要疗效解读从“PFS 获益明确，生存获益待证实”升级为“PFS 获益已报告，且 OS 在预设分析中也显示统计学显著改善”。

PD-L1 亚组层面，早期披露显示 PFS 在 TPS <1% 和 TPS ≥1% 均方向一致；后续结果 B 报告 OS 亚组 HR 分别为 0.64 和 0.68，方向也一致。不过亚组 OS 只作为补充一致性证据，原文未报告亚组统计检验边界，不能替代总体人群的层级检验结论。

### 5.3 安全性证据变化

安全性披露随随访延长变得更完整，但并非单纯“更安全”。结果 A 在 2025-02-28 截止时报告 3 级及以上治疗相关 AE 为 64% vs 54%，3 级及以上治疗相关出血为 2% vs 1%。结果 C 在 2026-02-27 截止时报告 3 级及以上治疗相关 AE 为 69% vs 59%，3 级及以上出血为 3% vs 1%。这说明更长观察下，两组高等级治疗相关 AE 均有更多事件被捕获，ivonescimab 组的数值仍高于对照组。

结果 B 称安全性可管理、与既往一致且未观察到新安全信号；该表述与结果 C 的定量补充并不冲突，但“未观察到新安全信号”不能解释为没有新增不良事件。对于免疫相关 AE、治疗相关 SAE、停药、减量、中断、死亡和暴露校正风险，4 条原文没有形成完整纵向更新。

### 5.4 重复、取代与冲突

结果 D 与结果 A 的 PFS 点估计和 HR 一致，结果 A 增加数据截止、随访和完整安全分类，因此结果 A 是更完整的早期 PFS 证据状态。两者不应被计为两次独立确认。

结果 B 与结果 C 使用相同数据截止、相同中位随访、相同 OS 中位数、HR、95% CI 和 P 值，因此是同一 OS 分析的重复/补充披露。结果 C 增加死亡事件数和更完整安全数据，应作为 2026 OS 证据状态中更完整的安全与事件数来源；但它不取代结果 B 中报告的 PD-L1 OS 亚组数值，因为结果 C 未列出这些亚组数值。

未见无法调和的核心疗效冲突。主要限制是部分披露缺少数据截止或随访，部分安全指标没有在后续披露中同口径更新。

## 六、总体判断变化

- **变化分类：** 加强
- **变化依据：** 随访从 10.3 个月延长至 21.4 个月；关键次要终点 OS 在预设分析中报告 HR 0.66、95% CI 0.50-0.87、单侧 P=0.0017，并达到 P<0.0049 预设边界；OS 亚组方向与总体结果一致。
- **受到限制的方面：** 安全性随更长随访显示高等级治疗相关 AE 和出血事件数值增加；后续披露未完整更新免疫相关 AE、治疗相关 SAE、停药/减量/中断、治疗相关死亡、暴露时间等关键安全成熟度指标。
- **仍不能得出的结论：** 不能把重复披露当作独立验证；不能仅凭原文断言长期安全性已经充分成熟；不能从亚组方向一致推导每个亚组均已独立达到统计学确证。

## 七、最终结论与下一次披露关注点

- **当前最成熟的证据状态：** HARMONi-6 在 532 例随机患者中，已报告 PFS 显著改善，并在 2026-02-27 数据截止、21.4 个月中位随访的预设 OS 分析中显示 OS 显著改善；目前最完整的 OS 疗效状态来自结果 B/C，最完整的定量安全更新来自结果 C。
- **相较最早披露的净变化：** 证据由 PFS 阳性拓展为 PFS 与 OS 均支持 ivonescimab 联合化疗相对 tislelizumab 联合化疗更有利；这显著提高了疗效结论成熟度。与此同时，安全性风险也因更长随访而更具体，尤其是 3 级及以上治疗相关 AE 和出血事件仍需持续观察。
- **仍需关注的信息：** 后续更长 OS 随访、OS 中位数和置信区间是否进一步稳定；PFS 是否有更新分析；各 PD-L1 亚组的正式统计状态；免疫相关 AE、VEGF 阻断相关 AE、治疗相关 SAE、停药/减量/中断、死亡和暴露校正安全性是否完整披露。
