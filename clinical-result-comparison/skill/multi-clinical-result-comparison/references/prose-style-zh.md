# 报告文体清单（中文）—— 交付物 prose 的取舍标准

本文件是**本 Skill 自带的**中文报告文体标准，用于定稿后的 prose 层面检查。它不是词表黑名单，而是**检查线索**：每个命中都回到上下文问一句「这句是空泛、重复、歧义，还是与报告文体不符？」，不是就不改。单看一个词、一个破折号、一个三项列表都不是修改理由。

标记：**〔强〕** = 见到一次就足以改；**〔弱〕** = 单独出现不构成理由，需要同段内有其它命中一起判断。

**报告专用的边界（先读这一条）**：报告允许正式度、名词化、被动、限定语和口径说明；不要为了「像人写的」把严谨表述口语化。第三节「**不写工作过程**」（本 Skill `SKILL.md` 与系统提示词里的过程叙述禁令）优先级**高于本清单的所有条目**。

## A. 结构级问题（先看段落形状，再看句子）

### A1.〔强〕铺垫代替陈述
段落先铺垫「为什么值得看」，再给出实际内容；或先讲方法，再讲结论。
**改写前：** 为了更全面地理解该药物的治疗定位，我们先梳理其作用机制，再来看临床证据。它是一个抗 PD-1 单抗。
**改写后：** 该药是抗 PD-1 单抗。
**保留：** 「为便于对比，以下数值均取自相同分析时点」——这类口径说明能改变读者采信，保留一次。

### A2.〔强〕过程叙述（报告最重的一条）
写给读者看自己的检索、筛选、计算、工具与流程。判据：讲工作还是讲事实。
**改写前：** 我们共检索到 27 条披露，去掉 9 条无终点数据者后，对剩余记录逐条抽取终点，得到如下结论：该方案优于对照组。
**改写后：** 该方案优于对照组（27 条披露中 18 条含可比较终点）。
**保留：** 「数据截止 2025-07-31，纳入 2 项 III 期试验」。

### A3.〔强〕自我解释与选择理由
说明为什么这么写、为什么这样选、犹豫过什么。这类推理属于过程，不属于报告。
**改写前：** 之所以只选这两项试验，是因为其余试验的终点定义不一致，无法比较；因此可以认为该药在一线治疗中确有优势。
**改写后：** 该药在一线治疗中优于对照（仅纳入终点定义一致的两项 III 期试验）。
**例外与措辞：** 宿主契约强制要求的声明（全文未取回、某条未纳入、口径限制）必须写，但要写成**材料自身的属性**——「本批材料均为摘要级、无全文记录」可以写，「本次运行无外网、PubMed→PMC 链路未能发起」属于工作条件，删。

### A4.〔强〕假对比抬价（不是 X，而是 Y）
两部分都提供信息，或否定部分纠正真实误解时保留。
**改写前：** 这不仅是给药方式的改变，更是治疗理念的跃迁：该药从静脉改为皮下注射。
**改写后：** 该药由静脉给药改为皮下注射。
**保留：** 该差异来自给药间隔，而不是剂量强度。

### A5.〔强〕意义拔高与空泛收尾
在事实后面追加评价性短句，或每节末尾都配一句「意味着…」。
**改写前：** 该试验达到主要终点，标志着该领域治疗格局迎来新变化，为患者带来新的希望。
**改写后：** 该试验达到主要终点。
**保留：** 这是该靶点首个达到主要终点的 III 期试验。

### A6.〔强〕逐句复述标题 / 说明文档自身
标题之后的句子只重复标题，或交代本文的组织方式。
**改写前：** 本节介绍安全性。下面说明该试验的安全性数据。3 级以上不良事件率为 12%。
**改写后：** 本节介绍安全性。3 级以上不良事件率为 12%。

### A7.〔强〕复述表格与图
正文把表格里的数字再念一遍，或在图注里重复表格数据。图表能表达的，正文不重复。
**改写前：** 如下表所示，试验组中位 PFS 为 9.4 个月，对照组为 6.1 个月，HR 为 0.62，p<0.001。
**改写后：** 试验组 PFS 优于对照组（HR 0.62，p<0.001）。

### A8.〔弱〕强凑三段式
三项并列当节奏使用，而不是因为事实恰好三条。
**改写前：** 该药具备有效性、安全性、便利性三大优势。
**改写后：** 该药有效，口服给药，3 级以上不良事件率为 12%。
**保留：** 导出、搜索和批量重命名是三个不同功能。

### A9.〔弱〕句式开头复读与串联
连续句子同一主语起头、同结构排比，只为制造节奏。

### A10.〔弱〕段落长度配平
为让每节视觉等长而注水或砍断信息。

## B. 措辞级问题

### B1.〔弱〕AI 高频词与包装词
「赋能、深度赋能、至关重要、无缝衔接、闭环、生态位、蓝图、里程碑式、全面赋能、全方位、多维度、深层次」。这些词在真实报告里很少出现，一段里两三处就已经足以动手；但单独一处不是判决：正式术语和工程含义明确时不算命中（如「闭环反馈」）。
**改写前：** 该药为这一治疗领域带来全新格局，具有重要意义。
**改写后：** 该药在该治疗领域为一线治疗提供了新选择。

### B2.〔强〕借权威
「业内普遍认为、专家指出、研究显示、有观点认为」而不给来源。
**改写前：** 业内普遍认为该方案是标准治疗。
**改写后：** 该方案被 NCCN 指南列为一线首选（引文）。
**保留：** 原文只给模糊归因时，保持其模糊程度，不替它编来源。

### B3.〔弱〕模糊关联
「有着密切关系」「与…密切相关」「在…方面表现突出」而不说具体角色。
**改写前：** 该公司与该靶点有着密切联系。
**改写后：** 该公司持有该靶点的一项 III 期资产。

### B4.〔弱〕限定词堆叠
同层不确定性的重复限定（「可能或许」「一定程度上大致」）。
**改写前：** 该结果或许可能提示一定的获益趋势。
**改写后：** 该结果提示获益趋势（未达统计学显著）。
**保留：** 该差异可能源于基线不均衡，尚无法确认。

### B5.〔弱〕回避「是／有」
用「作为…存在」「拥有着」「得以」替代直接判断。
**改写前：** 该药拥有着良好的安全性特征。
**改写后：** 该药安全性良好，3 级以上不良事件率 12%。

### B6.〔弱〕空泛评价词
「值得关注」「值得期待」「表现亮眼」「可圈可点」「令人瞩目」。要评价就给依据，给不出就删。
**改写前：** 该数据值得关注。
**改写后：** 该数据为同类药物中首个 5 年 OS 数据。

### B7.〔弱〕生造复合词与连接号
「研发-生产-商业化一体化」这类自造标签替换了已有定义。
**保留：** 端到端加密、剂量-效应关系等有具体含义的术语。

### B8.〔弱〕破折号当万能连接
反复用破折号制造悬念或替代分句关系。承担解释、插入功能的可保留。

### B9.〔弱〕粗体与装饰性标题当排版
在不帮助跳读处加粗、用 emoji 与箭头做标题。报告里加粗只保留给需要定位的关键项。

### B10.〔弱〕客服腔与承诺
「希望这对您有帮助」「如需我可以进一步分析」「如有疑问请随时沟通」。邮件与函件里的礼貌语有用途，报告正文里没有。

## C. 中文特有

### C1.〔弱〕层叠的「的」
长定语难解时拆分，不按字数阈值机械删。
**改写前：** 这是一个针对既往接受过多线治疗且伴有肝转移患者的探索性队列的分析。
**改写后：** 这是一个探索性队列分析，入组既往接受多线治疗且伴有肝转移的患者。

### C2.〔弱〕「进行＋动词」
**改写前：** 我们正在对安全性数据进行持续跟踪，并计划在下一版报告中进行更新。
**改写后：** 我们正在持续跟踪安全性数据，并计划在下一版报告更新。

### C3.〔弱〕被字句堆叠
改主动句时保持归因：「被认为与…有关」不等于「导致」。
**改写前：** 该信号被多次报告，被认为可能与肝毒性有关，但原因尚未确认。
**改写后：** 该信号被多次报告，可能与肝毒性有关，原因尚未确认。

### C4.〔弱〕四字词排比空转
「稳步推进、持续发力、不断完善、全面提升」。承载真实程度词时保留（「逐步放缓」）。

### C5.〔弱〕「随着…的发展」式开头
背景句没有独立信息时压缩。
**改写前：** 随着免疫治疗时代的到来，本文讨论该药的二线定位。
**改写后：** 本文讨论该药的二线定位。
**保留：** 随着随访延长，事件数从 42 增至 61。

### C6.〔强〕套话收尾
「综上所述，让我们拭目以待」「未来可期」「相信在不久的将来」。
**改写后：** 保留真实下一步或直接结束（「下一批数据预计于 2026 年读出」）。

### C7.〔弱〕半角/全角与引号混用
中文正文用中文标点；引文与结构化数据保持原样。

### C8.〔弱〕数字记号混用（同一数值两种形态）
同一份报告里 `10·3 个月` 与 `11.1 个月` 并存、`64%` 与 `64 %` 并存。来源材料本身常混用这些写法，照抄就会留下痕迹；统一的是排版，**取值与位数一个字都不动**。也顺手帮读者省掉「这两个是不是不同口径」的疑问。
**改写前：** 中位 PFS 11·1 个月（95% CI 9·9–NE），≥3 级出血 2 %
**改写后：** 中位 PFS 11.1 个月（95% CI 9.9–NE），≥3 级出血 2%
**边界：** 引用原句、代码、ID、URL、表格不动；不擅自补千分位或单位。

## D. 草稿与上下文残留

### D1.〔强〕谈论上一稿/谈论本文件
「本段为新增内容」「前面提到的框架」「如上一版所述」——变更日志、版本说明才需要前后差异。
**改写前：** 这里补一句，把主要终点改为 OS。
**改写后：** 主要终点为 OS。

### D2.〔强〕知识边界免责与猜测填充
重复免责声明、用推测填空、把「未报告」写成「不存在」。
**改写前：** 现有材料没有披露该试验的入组人数，信息较为有限。
**改写后：** 该试验未披露入组人数。

### D3.〔弱〕写给不懂行的读者
把读者已知的背景重讲一遍，把结论压到最后。报告读者知道背景，先给结论。

## 命中之后怎么改

1. 先整段重写，再回头核对数字与限定；不要只替换被标记的词。
2. 删掉的内容必须是空话或过程叙述；任何事实、口径、限定、来源都要留在正文里。
3. 改完读一遍：还像不像「在汇报工作」。若像，继续删过程叙述。
4. 同一段命中 3 条以上时，问题通常在段落结构，不在用词。

## 与机械扫描器（`scripts/tell-scan.py`）的关系

`scripts/tell-scan.py` 是同一层的**确定性**检查，随本 Skill 一起发布：

```
python3 -B /workspace/skills/multi-clinical-result-comparison/scripts/tell-scan.py /workspace/output/report.md
```

退出码：**0** = 无强命中 / **3** = 有强命中（可当门禁） / **2** = 用法或文件错误。`--json` 给明细，`--allow <ID,…>` 标注「已判断过、不改」的规则，`--weak` 让弱命中也算 3。

它的 `S-PROC-*` / `S-INFL-*` / `S-STRUCT-*` / `W-*` 编号与本清单条目**不是一一对应**：`S-PROC-01..07` 同时覆盖 A2、A3、A6、B10 与 D1，`S-INFL-01..03` 覆盖 A4、A5、B2，`S-INFL-04/05` 对应 B6，`S-STRUCT-01..04` 覆盖 A6、A7、C6 与标题复述，`W-*` 覆盖 B1、B3、B4、B5、B8、B9、C2、C3、C4、C5、C8 以及文档级计数（破折号 ≥3 处、粗体 ≥8 处、`W-FMT-MIXED` 数字记号混用）。**扫描器负责找候选，本清单负责判断。**

**强命中必须处理**（改掉，或用 `--allow` 明确标注已判断为不适用并说明理由）；弱命中只作线索。**扫描不改变任何一个数字**，也不授权删除任何 局限 / 缺口 / 未报告 声明或可比性告警。
