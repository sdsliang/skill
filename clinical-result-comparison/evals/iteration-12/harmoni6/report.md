# HARMONi-6 完整临床结果解读

**一句话结论：** 在既往未经治疗的晚期鳞状非小细胞肺癌人群中，HARMONi-6 的首次计划 PFS 分析显示，伊沃尼布单抗联合化疗相较替雷利珠单抗联合化疗显著延长 PFS；随后首次计划 OS 中期分析在较长随访和预设统计边界下显示 OS 也达到统计学显著，整体疗效证据得到加强，但 OS 仍不是最终分析，长期获益、应答持续性以及完整的长期安全性信息仍有限。[Ref 1; Ref 2; Ref 3; Ref 4]

> **证据范围：** 本报告仅整合所选的四份 HARMONi-6 结果材料。相同数据截止和分析的重复披露合并为同一证据状态，不计作独立验证。正文中的数字和关键事实均使用具体的 `[Ref 1]` 至 `[Ref 4]` 标明来源。

## 一、试验要回答的临床问题

- **目标人群：** 年龄 18-75 岁、既往未经治疗、病理学确诊、不可切除的 IIIB、IIIC 或 IV 期鳞状非小细胞肺癌患者，ECOG 体能状态为 0 或 1。[Ref 1; Ref 3]
- **核心治疗问题：** 在这一一线晚期鳞状非小细胞肺癌人群中，伊沃尼布单抗联合紫杉醇和卡铂，是否较替雷利珠单抗联合紫杉醇和卡铂改善临床结局并保持可接受的安全性。[Ref 1; Ref 3]
- **主要终点与检验框架：** 主要终点为由独立影像学评审委员会依据 RECIST 1.1 评估的 PFS；OS 为关键次要终点，并采用闭合序贯检验，先检验 PFS，PFS 达到统计学显著后再检验 OS。[Ref 1; Ref 2]
- **当前证据覆盖：** 所选材料覆盖首次计划 PFS 分析、首次计划 OS 中期分析、PD-L1 TPS 亚组、部分基线肿瘤特征及两个分析阶段的安全性结果；未提供 ORR、缓解持续时间、患者报告结局或生活质量的定量结果，也未提供最终 OS 分析。[Ref 1; Ref 2; Ref 3; Ref 4]

## 六、证据成熟度、矛盾与信息缺口

### 6.1 已经较为确定

- 在 HARMONi-6 的既往未经治疗的晚期鳞状非小细胞肺癌随机人群中，伊沃尼布单抗联合化疗相较替雷利珠单抗联合化疗的 PFS 结果达到统计学显著，且 PFS 结果在所报告的 PD-L1 TPS 亚组中方向一致。[Ref 1; Ref 4]
- 在 PFS 先达到统计学显著后，首次计划 OS 中期分析显示 OS HR 为 0.66，单侧 p=0.0017，达到预设的单侧 p<0.0049 边界。[Ref 2; Ref 3]
- OS 材料报告的 204 个死亡事件中，伊沃尼布单抗联合化疗组为 84 例、替雷利珠单抗联合化疗组为 120 例；这些数据与中位 OS 和 HR 的方向一致，但仍属于中期分析。[Ref 3]

### 6.2 仍属中期或有限

- OS 是首次计划分析，按约 225 个计划事件前的 204 个事件触发，不能写成最终 OS 分析。[Ref 2; Ref 3]
- OS 两组中位数的 95% CI 上限均为 NE，提示当前材料没有提供完整的上限估计；伊沃尼布单抗组两个 PD-L1 亚组的中位 OS 也均报告为 NE。[Ref 2; Ref 3]
- 亚组结果未报告交互检验，不能据两个 PD-L1 亚组的点估计推断治疗效应差异。[Ref 1; Ref 2; Ref 4]
- 长期安全性缺少暴露时长、停药、减量、中断和治疗相关死亡等信息，安全性成熟度低于 PFS/OS 的主要疗效证据。[Ref 1; Ref 2; Ref 3; Ref 4]

### 6.3 来源间需要解释的差异

- Ref 1 和 Ref 4 对 PFS 的中位数和 HR 完全一致，分别从完整结果和补充基线/亚组/安全信息角度呈现同一首次计划 PFS 状态；Ref 4 额外报告单侧 P=0.0094 的预设疗效边界，Ref 1 报告实际单侧 p<0.0001，二者分别是边界和实际检验结果，不构成冲突。[Ref 1; Ref 4]
- Ref 2 和 Ref 3 对 OS 的中位数、HR、置信区间、p 值、截止时间和随访时间一致；Ref 3 进一步报告 204 个死亡事件、84 对 120 的组间事件数及安全性分母，二者是同一 OS 中期状态的重复披露与互补细节。[Ref 2; Ref 3]
- PFS 状态中 ≥3 级治疗相关不良事件为 64% 对 54%，OS 状态为 69% 对 59%；两次分析的随访阶段不同，且 Ref 4/Ref 3 使用的事件定义或安全性分母存在差异，因此不能把比例变化直接解释为安全性恶化或风险排序。[Ref 1; Ref 3; Ref 4]

### 6.4 尚未报告但会影响判断的信息

- 最终 OS 分析以及更充分事件数下的长期生存估计未报告；现有 OS 结果不能替代最终分析。[Ref 2; Ref 3]
- ORR、完全缓解率、缓解持续时间、症状、患者报告结局和生活质量的结果未报告。[Ref 1; Ref 2; Ref 3; Ref 4]
- 停药、剂量调整、中断、治疗相关死亡、具体暴露时长和暴露调整后的安全性结果未完整报告。[Ref 1; Ref 2; Ref 3; Ref 4]
- 现有材料未提供足够细的基线分层数据、正式亚组交互检验或更多敏感性分析，因而不能判断哪些患者特征会改变治疗效应大小。[Ref 1; Ref 2; Ref 3; Ref 4]

## 七、整个试验的综合解读

### 7.1 疗效结论

HARMONi-6 先在主要终点 PFS 上显示伊沃尼布单抗联合化疗相较替雷利珠单抗联合化疗的统计学显著改善，随后在预设层级检验下的首次计划 OS 中期分析中再次达到预设统计学边界。[Ref 1; Ref 2; Ref 3; Ref 4] 这两项结果来自同一随机、双盲、头对头试验，构成从疾病控制时间到生存结局的连续证据链，而不是四份来源之间的胜负比较。[Ref 1; Ref 2; Ref 3; Ref 4]

在该试验、该人群和所报告的分析时间点内，随机比较支持伊沃尼布单抗联合化疗具有更有利的 PFS 和 OS 方向；OS 的临床意义仍应结合最终分析、长期随访和患者体验终点进一步判断，因为现有材料未报告 ORR、缓解持续时间、症状或生活质量。[Ref 1; Ref 2; Ref 3; Ref 4]

### 7.2 安全性与获益-风险

现有材料显示，伊沃尼布单抗联合化疗组在较早 PFS 状态和较长 OS 状态均报告了 ≥3 级治疗相关不良事件，且出血事件发生率高于替雷利珠单抗组的相应报告值；同时，早期材料报告两组 ≥3 级免疫相关不良事件分别为 9% 和 10%，OS 材料称未观察到新的安全性信号。[Ref 1; Ref 2; Ref 3] 这些结果支持安全性需要与疗效一并权衡，但由于事件定义、随访时间、暴露和分母并不完全一致，不能仅凭所列百分比给出总体安全性优劣结论。[Ref 1; Ref 2; Ref 3; Ref 4]

### 7.3 证据如何成熟

证据链从 2025 年 2 月 28 日的首次计划 PFS 分析发展到 2026 年 2 月 27 日、随访 21.4 个月的首次计划 OS 中期分析，整体判断得到加强：早期主要终点获益在后续关键次要终点的中期生存分析中仍呈有利方向，并达到预设统计学边界。[Ref 1; Ref 2; Ref 3] 但这种加强是同一试验内的更成熟终点证据，不是独立试验重复验证；由于 OS 仍为中期分析且长期安全性和患者报告结局信息有限，最终证据成熟度仍受到限定。[Ref 2; Ref 3; Ref 4]

### 7.4 当前最可靠的结论与下一步关注

- **当前最可靠的结论：** 对于既往未经治疗的不可切除 IIIB、IIIC 或 IV 期鳞状非小细胞肺癌、ECOG 0-1 的患者，HARMONi-6 的随机头对头结果支持伊沃尼布单抗联合化疗相较替雷利珠单抗联合化疗改善 PFS，并在首次计划 OS 中期分析中显示 OS 统计学显著改善。[Ref 1; Ref 2; Ref 3; Ref 4]
- **不能由现有材料支持：** 不能据此确认最终 OS 获益的大小、患者报告的生活质量改善、缓解持续时间优势、长期暴露下的完整安全性，或 PD-L1 TPS 对治疗效应的正式交互作用。[Ref 1; Ref 2; Ref 3; Ref 4]
- **下一次结果最应关注：** 最终 OS 分析、持续随访下的生存曲线和事件成熟度、停药及治疗相关死亡、暴露调整安全性、缓解持续时间，以及症状和生活质量结果。[Ref 1; Ref 2; Ref 3; Ref 4]
